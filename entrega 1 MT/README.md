# Proyecto integrador · Estructuras de Datos (ID 706132)

Juego tipo Metal Slug por ticks, en consola. Python 3.11 o superior.

## Instalar y ejecutar
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install pytest
python main.py
pytest
```

## Estructura
`specs/` (especificaciones SDD) · `estructuras/` (una por módulo) · `dominio/` (lógica del juego) · `tests/` · `docs/`.
